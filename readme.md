# Bienvenidos al curso de Teoría de la computación

Este repositorio está organizado en carpetas, cada una correspondiente a una semana de clase.

Dentro de cada carpeta encontrarán un archivo README con un resumen de los temas abordados durante esa semana, así como el material complementario correspondiente.

Este repositorio tiene como objetivo servir de apoyo al curso.
No sustituye el material publicado en Aulas ni, fundamentalmente, la asistencia y participación en clase.
